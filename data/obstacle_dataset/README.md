# obstacle_dataset

Auto-labelled, single-class ("obstacle") YOLO dataset generated from the
Gazebo simulation. Everything under this directory except this file is
git-ignored — the images, labels and `data.yaml` are regenerated by
`src/indoor_bot_evaluation/scripts/datagen.py`, not committed.

See [`docs/DATASET.md`](../../docs/DATASET.md#training-dataset) for how it
was generated, why it is a single class, the split-by-episode rule, and
known limitations.

To regenerate:

```
# inside the container, sim already launched with datagen:=true
python3 src/indoor_bot_evaluation/scripts/datagen.py --seed 0 \
    --episodes 150 --poses-per-episode 8
```
